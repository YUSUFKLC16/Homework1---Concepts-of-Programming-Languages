This is a homework project for a course on Concepts of Programming Languages. It demonstrates basic parsing using a custom LR parser implementation in Java.
>The Action and Goto tables were read and stored in appropriate data structures.
>The rules in the Grammar.txt file were loaded into memory as Production objects. Each input file was processed in order: the Stack, input, and performed action were tracked step by step. When necessary, shift, >reduce, accept, or error operations were executed. Once parsing was complete, a parse tree was generated and output visually. All results were saved in the target/output/ directory in the format outputX.txt (e.g., >output1.txt, output2.txt ...).

In short:
>This project doesn't just run — it teaches, observes, analyzes, and documents its output :)))
